Design a futuristic touchscreen-first kiosk UI for the iXperium Smart Industry application. The entire interface must be built around a “planetary orbit” navigation metaphor, viewed at a slight angle from above, like a stylized solar system. The main navigation is a horizontal elliptical orbit, not a perfect circle. It should feel premium, immersive, intuitive, and physically interactive.

CORE CONCEPT
- The UI is a planetary navigation system.
- There is always one large central “planet” in focus.
- Around it is a horizontally stretched elliptical orbit ring with multiple smaller “planet” nodes placed on the orbit.
- Each planet represents a menu item.
- The orbit must visually behave like a tilted solar system: planets at the back of the orbit appear smaller, partially obscured, darker, and tucked behind the central planet; planets at the front appear larger and more prominent.
- This must create a convincing depth illusion, as if the user is looking at a planet system from an elevated angle.

INTERACTION MODEL
- The orbit ring must be draggable by touch.
- Dragging left/right should rotate the ellipse smoothly and responsively.
- Include inertial momentum / physics behavior:
  - when dragged slowly, it follows precisely
  - when flicked quickly, it continues spinning with momentum
  - it gradually slows down with elegant friction
- Motion should feel fluid, premium, and tactile, like a high-end museum installation.
- The interface is for a large touchscreen, so all touch targets must be large and finger-friendly.
- No tiny buttons, no desktop-style UI, no clutter.
- All items must be easy to hit on a public interactive display.

NAVIGATION / TRANSITIONS
- When the user taps a planet on the orbit:
  - it should animate forward into the center
  - the camera should perform a smooth cinematic zoom-in
  - the selected planet becomes the new large central planet
  - a new child orbit appears around it with submenu items
- This pattern repeats recursively for submenu navigation.
- The animation should feel spatial and continuous, as though diving deeper into a planetary system.
- Transitions must feel elegant, polished, and visually understandable.
- Avoid abrupt screen swaps; everything should feel like one continuous 3D-inspired movement.

VISUAL STYLE
- Futuristic, clean, atmospheric, high-tech, but still readable and accessible.
- Blend:
  - smart industry / innovation
  - immersive exhibit design
  - subtle sci-fi
  - premium educational installation
- Dark background with depth, glow, soft gradients, subtle stars/particles/ambient haze.
- Planets can have different visual identities by category, but the system must remain coherent.
- Use soft lighting, faint orbit trails, elegant glow, glassy highlights, and depth blur where useful.
- The UI should feel like an interactive knowledge galaxy.
- Do not make it childish or gamey. It must still feel professional and institutional.
- Use clear typography with strong readability at kiosk distance.

DEPTH / PERSPECTIVE RULES
- Orbit is a horizontal ellipse.
- Front arc: items are larger and brighter.
- Side arc: medium scale.
- Back arc: items are smaller, lower contrast, and partially hidden behind the center planet.
- The center planet should overlap the back part of the orbit so the rear items visually disappear behind it or are only barely visible.
- This depth effect is essential.
- Add subtle shadowing, atmospheric fade, and scale changes to reinforce perspective.

LAYOUT REQUIREMENTS
- Design this as a widescreen landscape experience for a public touchscreen.
- The center of the screen is dominated by the active planet.
- Orbit must be wide and horizontal, stretched left-right.
- Provide strong visual hierarchy:
  - center planet = current focus
  - front orbit items = next likely interactions
  - back orbit items = contextual depth
- Include a minimal breadcrumb or back-navigation method that still fits the spatial metaphor.
- Avoid traditional sidebars or top nav bars dominating the design.

UX REQUIREMENTS
- Touchscreen friendly
- Clear navigation state
- Large hit areas
- Fast comprehension for first-time public users
- Fluid motion cues
- No tiny text
- No small dropdowns
- No complex UI chrome
- Designed for walk-up-and-use interaction in an exhibit environment
